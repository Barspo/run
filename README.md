# חיבור Garmin → מאמן הריצה

מערכת שמושכת את כל נתוני הריצה, השינה וההתאוששות שלך מ-Garmin Connect,
ובונה מהם דוח אחד שאתה מדביק בצ'אט. משם מתחילה העבודה על התוכנית.

---

## למה זה עובד ככה ולא אוטומטית

לגרמין אין API ציבורי לחשבונות פרטיים. הדרך היחידה להגיע לנתונים היא
להתחבר עם המשתמש שלך — וזה חייב לקרות **על המחשב שלך**, לא אצלי.
המשמעות המעשית:

- הסיסמה שלך נשארת אצלך. אני לא רואה אותה ואין לי גישה אליה.
- הנתונים הבריאותיים נשארים על המחשב שלך, בתיקייה שמוחרגת מ-Git.
- אתה שולט בדיוק מה מגיע אליי — רק מה שאתה מדביק.

## התקנה (פעם אחת, ~3 דקות)

### 1. הורדת הקוד

```bash
git clone https://github.com/barspo/run.git
cd run
git checkout claude/running-coach-garmin-j8fv17
```

### 2. התקנה

**Mac / Linux:**
```bash
./setup.sh
```

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

צריך Python 3.10 ומעלה. לבדיקה: `python3 --version`.
אם אין — [python.org/downloads](https://www.python.org/downloads/).
בהתקנה בווינדוס סמן **"Add Python to PATH"**.

## שימוש

**Mac / Linux:**
```bash
./run.sh
```

**Windows:**
```powershell
.venv\Scripts\python coach.py sync
```

בהרצה הראשונה תתבקש:
1. **אימייל** של חשבון Garmin Connect
2. **סיסמה** — לא מוצגת בזמן ההקלדה ולא נשמרת לשום קובץ
3. **קוד MFA** — רק אם מופעל אימות דו-שלבי בחשבון

אחרי התחברות מוצלחת נשמר טוקן ב-`.garmin_tokens/`, ובפעמים הבאות
לא תצטרך סיסמה או MFA (הטוקן תקף כשנה).

המשיכה הראשונה לוקחת 2–4 דקות (שנה של אימונים + 90 יום בריאות).
הרצות הבאות מהירות בהרבה — רק הימים החדשים נמשכים.

### התוצאה

```
data/coach_report.md
```

פתח אותו, **העתק הכל, הדבק בצ'אט.** זהו.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `./run.sh` | משיכה + בניית דוח. זו הפקודה הרגילה. |
| `./run.sh login` | בדיקת חיבור בלבד, בלי למשוך נתונים |
| `./run.sh report` | בניית הדוח מנתונים שכבר ירדו, בלי אינטרנט |
| `./run.sh sync --wellness-days 180` | חלון בריאות ארוך יותר |
| `./run.sh sync --activity-days 730` | שנתיים של אימונים |
| `./run.sh sync --refresh` | התעלמות מהקאש ומשיכה מחדש של הכל |

## מה נמשך בפועל

**אימונים** (שנה אחורה כברירת מחדל)
מרחק, זמן, קצב, טיפוס, דופק ממוצע ומקסימלי, פילוח זמן באזורי דופק,
Training Effect אירובי ואנאירובי, עומס אימון, קדנס, אורך צעד,
זמן מגע עם הקרקע, תנודה אנכית.

**בריאות והתאוששות** (90 יום כברירת מחדל)
משך שינה ושלביה, ציון שינה, שעת הירדמות, HRV לילי וסטטוס מול הבסיס
האישי שלך, דופק מנוחה, סטרס, Body Battery, Training Readiness.

**פרופיל ומדדי כושר**
VO2max, סף חומצת חלב (דופק וקצב), תחזיות זמנים למרחקים,
שיאים אישיים, Endurance Score, Hill Score, סטטוס אימון ועומס אקוטי,
משקל, ציוד ונעליים.

## תקלות נפוצות

**`Authentication failed (401)`**
אימייל או סיסמה שגויים, או שהחשבון ננעל. התחבר ידנית ל-
[connect.garmin.com](https://connect.garmin.com) כדי לוודא שהחשבון תקין.

**`Too many requests (429)`**
גרמין חוסם זמנית אחרי יותר מדי בקשות. חכה 15 דקות ונסה שוב.

**נתקע על בקשת קוד MFA**
הקוד נשלח לאימייל או לאפליקציית Authenticator — לא ב-SMS.

**הדוח יצא ריק או חלקי**
ודא שהשעון סונכרן לאפליקציית Garmin Connect לאחרונה. הסקריפט קורא
מהשרת, לא מהשעון — מה שלא סונכרן, לא קיים.

**`ModuleNotFoundError: No module named 'garminconnect'`**
ההתקנה לא רצה או שהרצת עם Python הלא נכון. הרץ `./setup.sh` שוב,
והשתמש ב-`./run.sh` ולא ב-`python3 coach.py` ישירות.
